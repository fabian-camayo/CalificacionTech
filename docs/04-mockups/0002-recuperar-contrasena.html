Ficha del mockup 0002 — Recuperar contraseña

1. Objetivo y pantalla

Permitir definir una nueva contraseña mediante un enlace enviado al correo registrado (CU.0001 secuencia alternativa, HU-04). Pantallas: solicitud, enlace enviado, nueva contraseña y confirmación.

2. Flujo y navegación

  • Inicio de sesión → «Recuperar contraseña» → Solicitud → «Enviar enlace» → Enlace enviado.
  • Abrir enlace (simulado) → Nueva contraseña → «Guardar contraseña» → Confirmación → Inicio de sesión.

3. Estados

  • Solicitud · Enlace enviado · Nueva contraseña · Contraseña inválida (no cumple letras, números y signo) · Contraseña actualizada.

4. Componentes reutilizados

Tarjeta de acceso, campos y botones del mockup 0001; mensajes de información, error y éxito.

5. Responsive

Tarjeta centrada de ancho máximo 420 px, adaptada a cualquier ancho de pantalla.

6. Notas de interacción

  • La regla de contraseña (letras, números y un signo) se valida al enviar.
  • El envío del correo y la apertura del enlace son simulados; no hay integración real.

7. Pendientes de aprobación

  • Respuesta cuando el documento y el correo no coinciden con un usuario (P-0002-01).
  • Vigencia del enlace y estado de enlace vencido (P-0002-02).
  • Estado de fallo del servicio de correo (P-0002-03).
  • Si se requiere un campo de confirmación de contraseña (no documentado; no se incluye).
